# CookinUp — frontend

Aplicação React para pesquisar categorias de ingredientes e montar uma lista para sua receita. O guia completo de instalação e execução local está no [README da raiz do repositório](../../README.md).

## Desenvolvimento

```bash
npm install
npm run dev
```

O frontend espera a API em `http://localhost:3000` por padrão. Para usar outra URL, defina `VITE_API_URL` em um arquivo `.env` neste diretório.
